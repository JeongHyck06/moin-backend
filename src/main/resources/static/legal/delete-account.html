계정 및 데이터 삭제 요청

모인 앱을 설치하지 않아도 계정 삭제를 요청할 수 있습니다.

이메일로 요청

  1. 계정 삭제 요청 이메일 보내기
  2. 모인 닉네임, 사용한 로그인 제공자(Apple·Google·카카오), 회신받을 이메일을 알려주세요. 비밀번호와 인증번호는 보내지 마세요.
  3. 운영자가 본인 확인 방법을 안내하고, 확인 후 계정과 관련 데이터를 삭제합니다. 요청 처리 결과는 회신으로 안내합니다.

앱에서 직접 삭제

로그인 → 마이페이지 → 회원 탈퇴 → 삭제 확인

삭제 범위

프로필, 인증 영상, 작성 댓글, 로그인 세션, 푸시 토큰, 신고·차단 기록과 프리즈 잔액이 삭제됩니다. 소속 그룹에서 탈퇴하며, 다른 멤버가 있는 그룹은 유지됩니다. 방장 권한은 남은 멤버에게 이전됩니다. 그룹의 기존 집계 기록은 남을 수 있습니다.

삭제된 파일은 접근을 차단하고 저장소에서 삭제합니다. 파일 삭제가 일시 실패하면 재시도합니다. 앱에서의 계정 삭제는 Apple·Google·카카오 계정 자체를 삭제하지 않습니다. 결제 이력이 있는 경우 계정 삭제가 자동 환불을 의미하지 않습니다.
